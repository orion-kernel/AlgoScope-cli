# MERGE SORT

> "A Divide and Conquer algorithm. It divides the input array into two halves, calls itself for the two halves, and then merges the two sorted halves."

---

## 󱫐 HOW IT WORKS
1. Divide the unsorted list into **n sublists**, each containing one element.
2. Repeatedly **merge** sublists to produce new sorted sublists until there is only one sublist remaining.
3. The merging process ensures the result is sorted by comparing elements from each sublist.

## 󰓡 COMPLEXITY
- **Worst Case:** O(n log n)
- **Average Case:** O(n log n)
- **Best Case:** O(n log n)
- **Space Complexity:** O(n)

## 󰄬 CHARACTERISTICS
- **Stable:** Yes
- **In-place:** No
- **Algorithm:** Divide and Conquer
