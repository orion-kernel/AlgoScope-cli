# BUBBLE SORT

> "The simplest sorting algorithm that works by repeatedly swapping the adjacent elements if they are in wrong order."

---

## 󱫐 HOW IT WORKS
1. Start from the **first index**, compare the element at this index with the next element.
2. If the current element is **greater** than the next element, **swap** them.
3. If the current element is **less** than the next element, move to the next element.
4. Repeat until the end of the array is reached. This is one **pass**.
5. Repeat the passes until no more swaps are needed.

## 󰓡 COMPLEXITY
- **Worst Case:** O(n²)
- **Average Case:** O(n²)
- **Best Case:** O(n) (when already sorted)
- **Space Complexity:** O(1)

## 󰄬 CHARACTERISTICS
- **Stable:** Yes
- **In-place:** Yes
- **Adaptive:** Yes (with optimization)
