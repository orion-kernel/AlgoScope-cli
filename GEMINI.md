# AlgoScope CLI

A terminal-based visualization tool for sorting algorithms, built with Go and the Bubble Tea framework.

## Project Overview
- **Purpose**: To provide an interactive and visually engaging way to understand sorting algorithms directly in the terminal. Currently, it implements **Bubble Sort**.
- **Main Technologies**:
    - **Go**: The core programming language.
    - **Bubble Tea (`github.com/charmbracelet/bubbletea`)**: The TUI framework for managing state and UI updates.
    - **Lipgloss (`github.com/charmbracelet/lipgloss`)**: Used for styling the terminal output.
- **Architecture**: Follows the Model-View-Update (MVU) architecture provided by Bubble Tea.

## Building and Running
- **Build**:
  ```bash
  go build -o algoscope main.go
  ```
- **Run**:
  ```bash
  ./algoscope
  ```
  Or using `go run`:
  ```bash
  go run main.go
  ```
- **Test**:
  Currently, there are no tests. To run tests when added:
  ```bash
  go test ./...
  ```

## Development Conventions
- **MVU Pattern**: State is managed in the `model` struct, UI logic in `View`, and state updates in `Update`.
- **Styling**: All UI styles (colors, bolding, etc.) should be defined using `lipgloss.Style` constants at the package level for consistency.
- **Animations**: State updates are triggered by `tickMsg` generated by `tea.Tick` to handle animations and visualization steps.
